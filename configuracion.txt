6. CÓMO CAMBIAR UNA CONFIGURACIÓN Y DESPLEGAR
--------------------------------------------------------------------------------
A) VARIABLES DE ENTORNO (producción):
   - Panel: vercel.com → proyecto "opinilab" → Settings → Environment Variables.
     Elegir entorno Production, poner nombre y valor, "Save". Después redeploy.
   - CLI:
       npx vercel env add <NOMBRE> production   (te pide el valor)
       npx vercel ls <NOMBRE>            (listar)
       npx vercel rm <NOMBRE> production (eliminar)
   - SIEMPRE redesplegar para que se apliquen: git push (si hay deploy automático) o
     `npx vercel --prod`.

B) TABLA settings (Supabase):
   - GUI: /dashboard/configuracion (botón "Guardar" por sección).
   - SQL Editor del panel Supabase: update public.settings set value = '...' where key='...';

C) CÓDIGO / CRONS / TEXTOS:
   - Editar el archivo, luego:
       git add -A
       git commit -m "descripción"
       git pull origin main   (por si hay cambios)   [si es posible]
       git push origin main
   - El deploy en Vercel es automático al hacer push a `main`
     (repo: https://github.com/Desarrollador-Estick/opinilab).

D) CAMBIAR PRECIOS / SERVICIOS:
   - La tabla services (name, description, category, base_price, billing_cycle)
     se modifica en Supabase. El cliente concreto puede tener custom_price en client_services
     (lo respeta run-monthly: si custom_price no es null, usa ese precio).
